## 游戏简介
《Trials in Tainted Space》（简称 TiTS）是一款科幻题材的成人文字冒险游戏。本汉化项目旨在将游戏界面、剧情、道具等内容逐步翻译为中文，方便中文玩家体验。

## 使用方法
1. 备份原始游戏文件。
2. 将汉化后的 JS 文件替换到游戏对应目录（如 `resources/app_Backup/add/`）。
3. 启动游戏
